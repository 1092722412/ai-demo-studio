# AI Demo Studio

## 启动第一批工作台

在 Windows 双击 `启动工作台.cmd`，首次会安装依赖并构建页面。也可在项目目录运行 `npm ci`、`npm run build`、`npm start`，再打开 http://127.0.0.1:17860。需 Node.js 22.12 或更高版本，以及已登录的本机 Codex。工作台运行期间可使用，关闭启动窗口后可重新启动，并从项目菜单继续查看历史。

1. 输入标题和需求，点击「开始讨论」。需要整理参考材料时，上传并等待提取成功，再点击「整理附件需求」。
2. 打开「确认制作范围」，添加条款或载入 Codex 提案，核对每项需求和预期结果，勾选确认后保存。
3. 全部条款确认后点击「生成系统」。本机 Codex 通过 MCP 读取已确认范围和工程内技能。左侧会显示工具调用、构建和发布进度。
4. 成功后点击「下载当前源码」取得 ZIP 和独立启动说明。重新生成失败或取消时，仍可下载上一次发布的源码。

工作台数据默认保存在项目的 `.studio`，包括 `studio.sqlite` 和 `projects/` 内的文件。更新个人安装的技能后，如需让本项目采用新版，请审核并更新工程内副本。

运行 `npm test` 检查工作台的任务、生成、发布和脚本交接，实际验证范围见 [当前状态](docs/STATUS.md)。`docs/UI设计图/v2-深色工作台` 保留为历史视觉参考。
