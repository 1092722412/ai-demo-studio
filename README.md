# AI Demo Studio

## 启动第一批工作台

在 Windows 双击 `启动工作台.cmd`，首次会安装依赖并构建页面。也可在项目目录运行 `npm ci`、`npm run build`、`npm start`，再打开 http://127.0.0.1:17860。需 Node.js 22.12 或更高版本，以及已登录的本机 Codex。工作台运行期间可使用，关闭启动窗口后可重新启动，并从项目菜单继续查看历史。

1. 在「新建与预览」输入标题和需求，点击「发送给 Codex」。也可点「使用示例」试用。附参考时可选 UTF-8 的 TXT、Markdown、JSON 或 CSV。
2. 本机 Codex 先调用工程内的 `.agents/skills/bid-demo-system/SKILL.md`，再通过 MCP 读取需求，生成页面、浏览器业务逻辑和本地 JSON 样例。每次任务均核对技能调用记录与文件摘要。缺失技能或未调用时，该次生成不会发布。
3. 点击「打开系统」实际操作，点击「下载源码」取得源码和启动说明。录制入口现提供页面标识与版本交接信息。
4. 工作台数据保存在项目的 `.studio/jobs`。新生成的演示工程提供本机预览、源码与初始数据。Node 负责启动和 JSON 数据服务，业务代码在独立网页中运行。生成逻辑可以包含本地查询、解析、比对和页面切换。涉及设备的样例演示使用合成数据。更新个人安装的技能后，如需让这个项目采用新版，请审核并更新工程内副本。

生成任务左侧可以继续和 Codex 对话，查看用户消息、Codex 回复与本轮工具调用。明确说先讨论时只回复，要求生成或修改时才尝试构建。每个项目只显示当前系统。修改期间继续使用现有预览，生成成功后替换当前系统。续聊复用本机 Codex 会话，项目历史以对话为主。

运行 `npm test` 可检查任务、预览、源码导出与录制交接。需求以 [首版产品需求文档](docs/01-PRD.md) 为准。`docs/UI设计图/v2-深色工作台` 保留为历史视觉参考，最新交互以 02 文档为准。
