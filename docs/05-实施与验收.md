# 05 MVP 实施路线与验收计划

五个阶段按门槛推进，G0 是设计评审，G1–G4 才进入实现。所有数值门槛均为拟定验收值，需在 G0 签认；历史实测值见 06。扩展矩阵独立登记，不通过不得宣称相应能力。

本期以[首版需求](01-PRD.md)为准。下方矩阵涉及版本管理、按运行编号查询的指标留作后续参考，本期验收按当前项目进行。

| 门槛 | 给后续 Codex 的任务 | 交付物与放行条件 |
|---|---|---|
| G0 设计冻结 | 审阅首版系统生成范围、录制审核与复跑口径 | 确认首条无源码需求、主屏配置、生成技术栈和验收指标。录制时另批准具体方案 |
| G1 架构与系统生成 PoC | 接通工作台、Codex、MCP、构建区和最小 Node 模板，从一段演示需求生成、交回并打开系统预览。用无桌面副作用的 Worker 检查录制任务 | 两端看到同一项目的需求和当前进度，源码及初态能独立复现预览。用模拟任务验证确认前无法开录、确认后可启动。通过 T01–T04、T18–T19 的生成与构建部分 |
| G2 桌面 PoC | 用旧告警规则项目复测桌面录制，再把同一执行链应用到新生成系统 | 生成系统同一构建和方案连续两次从空态达到刷新持久化，通过 T05–T10、T14 和 T16 的桌面部分。归档两个 run 和至少一次故障记录 |
| G3 媒体闭环 | 固定普通话依赖与试听选择，构建事件驱动的 HyperFrames 本地模板、预览与重渲 | 对两个合格 run 生成完整原片、配音、字幕、工程和成片，多段、遮挡和时间阈值通过 T11–T13；产出可重开的工程和 QA 表 |
| G4 MVP 交付 | 从空项目演练完整用户流程，验证需求修改后重生成和方案重新审批，走通成片退回、修订与交付 | T01–T20 全部首版项通过。按首版需求核对五类成果，记录两次录制的实测结果及已知边界 |
| 扩展 | 逐项测试 DPI／多屏、跨系统、长视频、其他宿主和新输入法 | 每个配置独立记录通过或受阻。根据结果修改支持矩阵，二期无须阻塞合规的单屏 MVP |

## 发布测试矩阵

发布验收使用从无源码需求生成的项目，采用同一构建快照和空记录 seed。两次录制连续进行，中间只允许 Runtime 正常收尾和自动准备，不许人工清理运行数据、重选 Network 或修补工程。“录前打开 Network”每次都在准备阶段执行。矩阵中的规则与阈值仅描述历史回归项目，生成主案例验收对应主业务字段和流程。每个案例记录测试机、版本、操作者、实际值和证据路径。

| ID | 操作／注入条件 | 通过与失败判据 |
|---|---|---|
| T01 跨入口 | Codex 发起测试任务，工作台打开其深链接；关闭宿主，稍后重连 | 2 秒内返回 runId（本地提议值），后台继续；两端版本、状态和最后事件序号最终一致。断线丢任务即失败 |
| T02 签批门禁 | 缺音色或字幕设置送审；无审批开录；批准后分别改旁白、seed、适配器；撤销 | 缺字段具体可见；过期/撤销版本、Agent 自签均无法进入真实输入或录制；原批准保留审计 |
| T03 幂等与竞争 | 两端同时用同一 requestKey 启动；同键改载荷；不同项目同时抢桌面 | 同载荷一个 run，同键异载荷冲突；另一桌面任务排队或显示占用。任一重复保存即失败 |
| T04 后台与恢复 | 断 MCP；重启 Runtime；在录制或渲染中终止 Worker | 宿主断开无影响；真实输入中断后无自动接续；能区分未封闭原片和已封闭原片；只有归属已核实的进程被收尾 |
| T05 干净初态 | 保存项目清单，按同一批准版本连续运行 A、B | 两次各自运行前 UI 为空、文件满足初态；均从零创建一条。各自 runId、数据目录、Edge profile、日志和产物不同 |
| T06 双重验证 | 新生成系统写入姓名、来访事由后保存和回读，再真实 F5。回归案例分别检查阈值 80 和记载状态 | 刷新后 UI 唯一匹配所验证的业务字段，磁盘恰一条且字段吻合。刷新前的旧 DOM 或仅有成功提示均不通过 |
| T07 源数据与边界 | 比较源清单；测试适配器指向原目录、junction 和意外新增文件（使用牺牲副本） | 外指路径准备阶段拒绝。内容变化、新增和原有文件消失均报错并封存，不在真实源工程注入故障 |
| T08 真实输入 | 审查工具注册和每一步事件；尝试注入未支持动作；录制指针轨迹 | 禁 CDP 写入、脚本模拟点击和业务接口写入；真实指针有移动与停留。合法保存引起的页面自身 HTTP 请求正常出现 |
| T09 坐标与失焦 | 目标越界、重复、被遮挡；移动后改变布局；用户切换窗口或锁屏 | 下一次输入前停止，记录窗口、目标与最后帧，绝不误点任务栏或无关应用。校准三点最大误差拟 ≤3 物理像素 |
| T10 全桌面 | 准备期按 F12 打开并选择 Network；录前、首次点击、保存和末帧抽查 | 原片和成片均含完整主屏、任务栏、指针及可见 Network。录中无 DevTools 操作，画面尺寸与当前桌面逐像素匹配（原片） |
| T11 TTS／字幕 | 同一锁环境合成 4 段，实测音长、语言与 cue；断网重跑缓存命中及未命中两例 | 命中复用相同哈希；缺缓存显示可重试失败且不消耗桌面录制。试听音色与批准一致，字幕顺序正确、非负、无重叠、未越过原片 |
| T12 同步／可读 | 样片首、中、末段和每个“保存／刷新”事件逐帧对齐，目测任务栏、卡片与字段 | 锚点画面与对应语音起点偏差拟 ≤250 ms，结尾累计偏差 ≤300 ms（按原片 PTS、解码音频起音测量，扣除已声明前导静音）；关键结果画面至少 1.2 秒且覆盖对应讲解。任何语义先于业务成功即失败 |
| T13 后期交付 | 从固定模板重开 HyperFrames 工程，本地重渲；移动字幕再渲 | ffprobe 检到 H.264/AAC、正时长、分辨率正确；时长与时间轴差 ≤1 输出帧或已记录的音频编码填充。原片哈希不变；字幕、框、说明无裁切遮挡；旧版仍可追溯 |
| T14 失败停止 | 保存回读超时、FFmpeg 退出、空间不足、用户取消、Edge 人工关闭分别测试 | 停后不再发输入、不重复提交；保留失败步骤、部分文件、最后截图、退出码和日志；可从新 run 重录。残留占锁或把失败片标为已验收即失败 |
| T15 AI 草稿 | Codex 读功能资料生成草案，刻意给出一个不存在的目标和一个事实错误；由人修订后执行 | 未知目标阻塞执行，业务错误可追溯来源并退改，修订须重批。保存模型生成稿、人工差异、最终版和 run。仅手工示例通过不能替代此项 |
| T16 桌面和环境 | 测指定单主屏正常配置、非批准 DPI、第二屏、RDP 断开；验证停止热键 | 正常配置跑通；不支持配置在首个业务动作前说明原因；中途变化安全停止。无冻结、无意外前台窗口 |
| T17 审片与交接 | 在具体时间点退回，改字幕颜色重渲，再通过；新终端打开项目索引 | 用户可定位问题帧、前后版本和批准记录。交付引用已审核文件哈希；可从成片定位真实操作、日志与隔离数据 |
| T18 从需求生成 | 仅提供一份访客预约演示需求。从空工作区发起，交回生成源码、样例、需求映射和启动说明 | 生成的页面与业务逻辑可在独立目录启动，页面加载和空态正确；已有系统导入、静态页面预览代替可运行系统、人工补项目源码均不能通过 |
| T19 构建与契约绑定 | 修改需求条目并重新生成，尝试使用旧方案和审批。注入缺失 DOM 绑定、非法路径或未就绪版本 | 新版本各自留痕，旧批准无法用于新构建。无法定位或构建未就绪时阻止录制，并显示原因。保留旧视频及其原构建引用 |
| T20 需求到成片 | 在 T18 新生成系统上用真实鼠标键盘创建预约、保存并 F5，依同一构建和获批方案复跑，再审核导出 | 每次均从空态开始且刷新后可见同一条记录，隔离 JSON 唯一匹配。交付可启动源码及可播放视频，视频、审批、契约和源码可按 buildId/runId 对照。仅旧项目录制成功时整体验收失败 |

**资源与性能记录。** G2 记录采集实际帧率、标定误差、进程退出、单次占用空间；G3 记录渲染耗时、峰值内存、A/V 起止偏差。历史 15 fps 成片不等于 15 fps 原生采集。出现卡顿漏掉关键动作即失败，发布分辨率与帧率须用目标机实测。计划时长、单次采集空间和预计保留空间应在录制前可见，空间不足直接阻塞。

## 扩展验证与验收材料

| 待验证项 | 建议配置与采样 | 通过后才可声明 |
|---|---|---|
| DPI、多显示器 | 单屏 100/125/150%；双屏同／异 DPI、负坐标、副屏窗口 | 对每一配置检查三点映射、实际点击、任务栏覆盖与失焦停止；MVP 默认单屏，副屏不作为软降级 |
| 长视频、多段漂移 | 先做四段短片，再做 10 分钟 ≥20 段；首中末及每次提交点测漂移 | 连续无截断、关键点满足 T12、无累计漂移，资源峰值可复现；短片通过不能推广到长视频 |
| 其他 Harness | 具体版 Codex 卡片、企业／普通 WorkBuddy、具体 DSH web profile 分表 | 记录工具发现、执行、资源协商、卡片、回调、文本降级与重连；把“不支持”和“未测”分别登记 |
| 泛化 | 同机另一 Node + JSON 项目、自定义 DOM、一种中文输入法、不同 Edge 版本 | 隔离、观察、真实输入、同步、复跑均有证据；每个新适配器独立放行 |

每次验收包至少含原始演示需求、生成源码及启动说明、构建和功能映射、测试配置、批准版本和摘要、原目录前后清单、初末态摘要、序号事件、录前截图、原片、音频/cue、时间轴、HyperFrames 工程、成片、关键帧、ffprobe 报告和人工结论。失败测试保留能复现的最小证据与清理结果。**硬停止条件**包括无审批、源目录变化、业务操作走错输入通道、误点其他窗口、录中触碰 DevTools、漏录任务栏、伪造回读或未经审核交付。
