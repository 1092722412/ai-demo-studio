# 02 工作台与 Agent 交互

更新日期：2026-11-26。以下为目标交互，已实现范围见 [当前状态](STATUS.md)。产品规则以 [PRD](01-PRD.md) 为准。

## 入口与页面

沿用“新建与预览”“录制与审片”两个项目入口，增加接入及表现配置入口；不引入独立的历史版本、运行列表或审批中心。

| 位置 | 内容与操作 | 结果 |
|---|---|---|
| AI 接入设置 | 选择接入方式，查看连接状态、可用能力和失败原因。首版实现 Codex，其他入口在实现前不显示为可用。 | 项目使用所选接入；已有会话不能无条件跨 Agent 迁移。 |
| 新建与预览 · 材料 | 新建/打开项目、提交标书或粘贴条款、补充需求。 | 展示原文出处、演示要求、待核实内容和制作进度。 |
| 新建与预览 · 系统 | 查看生成过程、打开实际系统、下载源码、提出修改。 | 根据反馈修订系统；失败显示原因，不能仅凭服务启动声称业务正确。 |
| 录制与审片 · 方案 | 阅读/编辑步骤、输入、预期结果、讲解和标注，查看功能缺口。 | 保存草稿；根据实际系统准备执行脚本。 |
| 录制与审片 · 开始 | 查看方案、当前配置和录前检查，主动点击“开始录制”。 | 准备通过后让位给目标 Edge，执行脚本并采集。 |
| 录制与审片 · 进度 | 查看准备、录制、后期进度、停止入口及失败步骤。 | 停止后不再发业务输入；保留已有文件并说明完整性。 |
| 录制与审片 · 成片 | 播放原片和后期视频，按时间点提意见或通过成片。 | 根据修改内容安排重渲或重新准备录制，由人发起需要的新录制。 |
| 项目成果 | 打开或下载五类成果，尚未产出时显示当前状态。 | 导出当前可交付文件，失败片不标成通过。 |

## 方案准备

1. 对照条款、当前源码、业务规则、样例和实际页面，建立“要求—功能—展示结果”关系。
2. 根据功能定制操作路径和输入，独立推导预期结果。查询、筛选、编辑、保存或刷新仅在该功能需要时加入。
3. 将目标关联到当前页面已有的稳定标识或可访问名称，记录出现条件。不存在或不能唯一定位时提示具体步骤，不自动选择第一个。
4. 展示业务语言写的操作、预期画面和讲解；技术定位按需展开。系统修改后复核受影响步骤，保留仍适用的人工编辑。
5. 草稿允许不完整；有必需字段缺失、功能缺口或未支持动作时不能进入正式执行。

例如按条件查询，按钮提交和条件改变即更新需要不同脚本。具体命中记录由当前样例和业务规则推导，不能套用另一项目的预期。

## 表现配置

工作台保存默认音色、鼠标移动时长/点击前停留、字幕字体/字号/颜色/底色/透明度/位置；项目可覆盖。页面显示继承来源和生效值，可试听当前讲解、查看字幕样张。示例值不是用户默认选择。

用户开始录制后，任务使用开始时确定的方案与配置。录制中改配置不影响正在执行的任务；下次准备时生效。只改后期样式可单独重渲。正式录制期间工作台不抢焦点、弹出通知或打开预览。

## 执行与反馈

录前按环境、演示数据、目标页面、Network、录屏范围和音频依次展示检查结果。数据准备可直接修改或重置本项目演示数据，页面说明将做的准备。

失焦、目标歧义、结果检查失败、录屏异常或用户停止时，显示发生了什么、最后完成哪一步、哪些成果可用。已发出的保存结果未知时不自动重发；重录前按方案重新准备初态。停止方式与热键须在实现时检查可用性。

后期反馈区分业务动作/讲解内容与纯样式修改：前者评估是否需重录，后者复用原片。只有当前播放的成片获人工通过才显示已验收；替换成片后重新审核。

## 成果与参考图

源码附启动说明；方案可阅读；脚本附执行说明；原片和成片可播放。允许一个项目保留多个成果文件，不提供版本比较或运行编号管理。

[已有界面图](UI设计图/v2-深色工作台)是历史视觉参考，未在本轮重绘；如图中文字或按钮与本文冲突，以本文为准。外部客户端卡片/插件不是首版必要页面。

## 页面操作与接口对应

以下接口均为 [03 详细设计](03-技术架构.md)的新接口，尚未接入当前 UI。

| 用户动作 | 请求与状态反馈 |
|---|---|
| 新建项目 | POST /api/v1/projects；取得项目后输入材料，不自动调用 AI。 |
| 整理标书要求 | 附件上传后看提取任务；POST messages 的 purpose=requirements。原文提取失败时保留文件并给原因。 |
| 确认制作范围 | 编辑条目并 PUT requirements；未确认的项以文字提示，不允许直接生成系统。 |
| 提问/生成/修改 | 分别发送 purpose=discuss/system；携带 requestId，按钮双击或网络重试复用同一个请求。已存在系统可继续预览，失败时保留。 |
| 查看过程 | 按 taskId 订阅 SSE，以 callId 更新工具行；刷新页面先 GET project 恢复活动任务，再从 lastSeq 续读。 |
| 更换 AI 接入 | 显示已配置且 probe 通过的连接；换连接新开会话，保留可读聊天及当前项目资料，不声称继承另一工具内部记忆。 |
| 设计方案 | purpose=plan；返回草稿及待核实内容。保存用 PUT plan + If-Match，遇冲突先展示服务端内容，保留本地未保存文本。 |
| 调整配置/试听 | GET settings 展示生效值和来源；移除项目覆盖后回到全局值。voice 为空时引导在设置区选择一次，试听产生独立音频任务。 |
| 准备脚本 | POST scripts；字段问题定位到步骤，成功后显示脚本下载与“开始录制”。 |
| 人开始录制 | POST recordings，传 planToken/scriptArtifactId；409 提示方案变化或桌面占用，202 后显示准备阶段并让位给 Edge。 |
| 停止 | POST task cancel；先显示正在停止，收到 cancelled 才显示已停止；不能收到 202 就立即显示停止完成。 |
| 修改/通过成片 | 评论带 videoArtifactId 和时间点。纯样式调整 POST renders；新视频回到待审核，通过动作只针对当前视频。 |
| 取得成果 | GET artifacts 取摘要；按 artifactId 下载/播放，不从前端拼本机文件路径。 |

首次进入设置页显示接入方式和安装/登录状态。API Key 页面包含供应商、服务地址、模型及一次性密钥输入，保存后只显示“已配置”；没有实现的适配器不可选择。Codex 额度/登录失效提示作用于 AI 接入，不把它显示成桌面录制失败。

错误统一显示“发生了什么、受影响步骤、可做的下一步”，不展示令牌、堆栈或原生工具协议。阶段来自 Project.stage，执行状态来自 Task.state，两者分别呈现；不把“任务成功”自动写成“业务验收通过”。
