# AI Demo Studio 首版产品需求

更新日期：2026-11-26。本文记录产品范围；当前实现见 [代码地图](ARCHITECTURE.md)，实施顺序见 [实施与验收](05-实施与验收.md)。

## 产品与用户

AI Demo Studio 是面向外部用户的投标演示制作工作台。用户提供标书或演示条款，产品通过 AI 完成要求分析、演示系统开发、演示方案和脚本编排、真实操作录屏及后期制作。人负责审核、主动启动录制和验收成片。

产品支持两类 AI 接入：已有 Codex、WorkBuddy 等工具时接入其 Agent 能力；只有 API Key 时使用产品内置的 Agent 执行能力。首版先做好 Codex，架构保留两类接入的扩展边界，后续接入能力逐项验证。

## 首版主流程

提交材料 → 核对演示要求与原文出处 → 生成可运行系统 → 试用并调整 → 按实际功能生成方案与脚本 → 人查看方案并启动录制 → 自动执行、采集及后期制作 → 人审片、提出修改并交付。

| 能力 | 首版目标 |
|---|---|
| 材料与需求 | 提取演示功能、评分要求、限制和原文出处；无法确定的内容明确标记，不能编造功能。 |
| 系统生成 | Node.js + JSON 基础模板，一个本地业务闭环及少量页面。交付源码、样例与独立启动说明。 |
| 系统试用 | 可打开实际页面并反馈修改。需要保存的功能能保存和刷新回读，查询类功能按实际规则检查结果。 |
| 方案与脚本 | 根据当前源码、页面和业务规则定制步骤、输入、定位、预期结果、讲解及标注。缺少功能或无法定位时指出具体缺口。 |
| 人工启动 | 查看当前方案和配置后，由人在工作台点击开始；AI 不自动开录。录前准备失败时显示原因。 |
| 真实录制 | PyAutoGUI 执行业务操作，Playwright/CDP 只观察；FFmpeg 采集完整桌面、任务栏和鼠标。录前 F12 停在 Network，录中不调整 DevTools。 |
| 后期与审片 | Edge TTS 配音，HyperFrames 制作字幕、标注及成片。按真实操作事件对齐；可按时间点提意见。 |
| 交付 | 同一项目提供演示系统源码、演示方案、自动化执行脚本、原始录屏和后期视频。未完成或失败的文件明确标识。 |

## 配置与数据

音色、鼠标速度和字幕样式作为可保存的配置项，提供工作台默认值和项目调整；录制准备时展示实际生效值，不强制每次重新选择。在线配音使用所选讲解文本，接入设置说明联网用途。

演示数据按录屏需要直接准备、修改、清空或重置，不建设原数据保护、隔离运行副本和前后哈希比对。准备操作限定在当前演示项目；源码及五类成果仍须能取得，录制重置不能顺带清除交付文件。

## 首版边界与验收

- 暂定 Windows、Edge、单主屏。具体分辨率、缩放和性能指标在实际使用时记录。
- 产品版本管理、运行编号及其查询界面、完整视频编辑器、生产级外部系统联动不进入首版。
- 对外赋能不等同于云端多租户已定稿；当前按可分发的本机工作台设计，其他交付形态后续确定。
- 验证案例和业务验收由用户负责。开发者负责获准变更的工程检查，不自行选案例或启动演示验证。
- 用户以自己的条款核对功能、方案、真实画面、配音字幕及五类成果。具体业务断言随案例确定，不固定为新增记录或保存刷新；不设统一两次复跑要求和未经确认的毫秒、像素门槛。

业务动作变化需重新准备方案并由人再次启动录制；只改字幕样式或标注位置时可用已有原片重渲，成片修改后重新审片。
